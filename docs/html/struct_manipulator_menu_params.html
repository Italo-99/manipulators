Detailed Description

Struct to hold the parameters for the ManipulatorMenu class.

Parameters
node_nameName of the node.
ros_freqFrequency of the node.
manipulator_nameName of the manipulator, must match the one in the manipulator planner.
planning_groupName of the planning group specified in the srdf, must match the one in the manipulator planner.
joint_namesNames of the joints, must be members of the planning group.
base_link_nameName of the base link, used as a reference frame for coordinates.
tcp_position_toleranceTolerance for the position of the end effector (m).
tcp_orientation_toleranceTolerance for the orientation of the end effector (rad).
joint_toleranceTolerance for the position of the joints (rad).
known_poses_pathFull path to the yaml file with the known poses (leave empty if not used). Known poses are defined as their name and a vector of joint angles in degrees eg: home: [0, 0, 0, 0, 0, 0].
gripperType of gripper to be used, must be in the list of available grippers.
gripper_group(specific for gripper type robotiq_85) Name of the gripper group, must match the one in the srdf.
gripper_IO_cmds(specific for gripper type toolIO) Tool IO commands for the gripper, must be in the list of available grippers.

Available grippers:

  • no_gripper: No gripper, only the manipulator is used.
  • robotiq_85: Robotiq 85 gripper, actuated through a service.
  • toolIO: Generic gripper actuated through the tool IO of the robot.
